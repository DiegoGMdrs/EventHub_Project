# Aplicação EventHub: Plataforma de eventos populares

## Equipe:
- Arthur dos Santos
- Diego Medeiros

## Objetivo Geral
Desenvolver o EventHub, uma aplicação web para ajudar pessoas a descobrir eventos e
experiências. A plataforma apresenta eventos populares com informações como categoria,
data, horário, local e preço, além de oferecer navegação por categorias e recursos visuais
para explorar as opções disponíveis.
O projeto está sendo construído inicialmente como uma interface web com HTML, CSS e
Javascript, usando carrosséis para exibir categorias e eventos. A proposta é evoluir essa
base para uma plataforma mais completa, que possa incluir busca funcional, cadastro e
login de usuários, publicação de eventos por organizadores, integração com uma API e
persistência de dados.
- Página inicial de descoberta de eventos;
- Categorias como música, esportes, gastronomia e tecnologia;
- Cartões de eventos com informações básicas;
- Campo visual de busca por evento e localização;
- Carrossel de categorias e apresentação de imagens.
